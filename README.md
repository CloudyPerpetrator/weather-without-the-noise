# Weather, Without the Noise

A live city weather app with current conditions and a five-day forecast.

## Features

- Search cities with Open-Meteo geocoding
- Current temperature, feels-like temperature, humidity, and wind
- Five-day forecast and Celsius/Fahrenheit switching
- Loading and error states
- Responsive layout

## Data

Uses the public Open-Meteo geocoding and forecast APIs. No API key is required.

## Run locally

Requires Node.js 20.11 or newer.

```bash
npm install
npm run dev
```

Open http://localhost:3000.
